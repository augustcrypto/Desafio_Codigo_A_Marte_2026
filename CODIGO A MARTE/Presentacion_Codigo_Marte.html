🌟 Hackathon Argentina Espacial 2026 - Desafío del Hábitat

El Código Marte es el primer ecosistema autónomo extraterrestre de origen argentino. Sistema integrado de soporte vital diseñado para garantizar la supervivencia de 4-6 astronautas durante 18-36 meses en Arcadia Planitia, donde el hielo subsuperficial está confirmado a solo 1-3 metros de profundidad.

Implementado en Rust, C++ y Python con tecnologías argentinas de vanguardia: INVAP + UNLP (reactores nucleares), CONAE + UNLP (comunicaciones espaciales), CONICET (biotecnología), INTA (agricultura extrema).

🛠️ Sistemas Implementados

🌡️
Control de Temperatura
Gestión térmica para ciclo marciano de ±60°C diarios. Reactor nuclear micro-SMR (INVAP) como fuente principal de calor. Paneles de aerogel de sílice, heat pipes de amoníaco y control PID con redundancia triple.
Demo HTML5 Docs Código Rust
🛡️
Protección contra Radiación y Bit Flips
4 capas de protección: regolito compactado (50-80cm), polietileno (15cm), superbobinas superconductoras (campo magnético 5-10mT), y ubicación subterránea (1.5m). TMR + ECC + Hamming Code contra SEU. Reducción >90% de radiación GCR.
Demo HTML5 Docs Código Rust
💨
Control de Oxígeno y Atmósfera
Mezcla 21% O₂ / 79% N₂ a 70 kPa. Sistema Sabatier (CO₂ + H₂ → CH₄ + H₂O). 2 sistemas MOXIE independientes + cartuchos LiOH de emergencia (72h). Zeolitas regenerativas y aminas líquidas (CONICET).
Demo HTML5 Docs
🔄
Conversión CO₂ → O₂ (MOXIE-2)
Electrólisis de óxido sólido a 800°C. Produce 25g/h de O₂ por unidad desde atmósfera marciana (95% CO₂, 600 Pa). Tecnología INVAP de reactores de alta temperatura. Redundancia N+2.
Demo HTML5 Docs
💧
Ciclo del Agua
Recuperación >98% del agua. Extracción de hielo local (Arcadia Planitia, 1-3m profundidad) con meltsondes térmicas: 5-10 L/día. Biorreactor MBR + ultrafiltración + UV. Procesado de percloratos por electrólisis. Purificación EDL (electrodinámica de plasma).
Demo HTML5 Docs
🔋
Sistema Energético Dual
Solar: 80 kWe pico (500m², bifaciales con limpieza electrodinámica). Nuclear: Reactor micro-SMR INVAP 40 kWe continuo (10+ años sin recarga). Baterías Li-S (48h reserva) + pila H₂/O₂ emergencia (72h). Opera 100% nuclear durante tormentas de polvo globales.

Comunicaciones Cuánticas Híbridas RF/Óptico
Sistema innovador argentino (INVAP + CONAE): Enlace cuántico a través de láser óptico con Distribución de Clave Cuántica (QKD). Incluye posible satélite argentino con tecnología cuántica de comunicaciones y cifrado de clave post-cuántica de IBM para máxima velocidad y seguridad. Conmutación automática a RF durante tormentas de polvo. Latencia 4-24 minutos.

🔐 Sistema de Comunicaciones Cuánticas

Enlace Cuántico Óptico + Satélite Argentino

🛰️ Infraestructura Argentina

  • INVAP + CONAE: Satélites repetidores en órbita marciana (experiencia SABIA-Mar, SARE)
  • Red de Espacio Profundo: Estación CLTC en Neuquén + Radiotelescopio LLAMA
  • Satélite Cuántico Argentino: Tecnología cuántica de comunicaciones con cifrado post-cuántico
  • Colaboración IBM: Cifrado de clave post-cuántica para seguridad contra computadoras cuánticas futuras

⚡ Sistema Híbrido RF/Óptico

  • Antena Dual: Parabólica de fibra de carbono pulida que actúa como reflector de radio Y espejo óptico para láser
  • Días Despejados: Transmisión láser a velocidades de gigabits por segundo con QKD (Distribución de Clave Cuántica)
  • Tormentas de Polvo: Conmutación automática a radio (banda Ka/X) que atraviesa el polvo sin atenuación
  • Retransmisión Satélite-Satélite: Cross-link láser entre satélites en zonas despejadas
  • Seguridad Cuántica: Cifrado imposible de interceptar sin detección, preparado para era post-cuántica

🔬 Tecnología de Vanguardia

El sistema de comunicaciones cuánticas representa la colaboración entre Argentina e IBM para crear la infraestructura de comunicaciones espaciales más segura y rápida jamás diseñada. La tecnología de cifrado post-cuántico garantiza que las comunicaciones permanezcan seguras incluso ante el desarrollo futuro de computadoras cuánticas capaces de romper el cifrado tradicional.

Ventajas clave: Velocidad de gigabits/segundo en condiciones óptimas, seguridad cuántica inviolable, redundancia automática ante condiciones adversas, y capacidad de expansión para futuras misiones a Marte y más allá.

🌱 Huerta Marciana - Producción de Alimentos

El módulo de biosoporte provee el 35-50% del aporte calórico de la tripulación mediante cultivos en ambiente controlado (CEA). Tecnología INTA de agricultura de precisión en ambientes extremos.

  • Lechuga NASA Veggie: 3.5-5.0 kg/m²/mes (28-35 días) - Vitaminas A, C, K
  • Papa/Batata adaptada: 4.0-6.0 kg/m²/mes (90-110 días) - Calorías, K, B6
  • Soja nano: 1.5-2.5 kg/m²/mes (80-90 días) - Proteína completa
  • Microalgas Spirulina: 0.5-1.0 kg/m²/mes (continuo) - Proteína 60%, B12
  • Sistemas: Hidroponía (50% más rápido), Aeroponía (95% menos agua), Regolito modificado

🤖 Robótica Argentina

  • HERMES-1/2: Brazos robóticos 6-DOF (INVAP/CONAE) - Instalación, reparación, sellado
  • GUARANI-1/2/3: Rovers autónomos (CONICET/Novabot) - Inspección, extracción de hielo
  • CHASQUI-1: Dron atmosférico (INVAP/FuABio) - Reconocimiento aéreo, detección de fisuras
  • ATLAS: Robot humanoide (UTN/ITBA) - Mantenimiento, asistencia médica
  • Impresión 3D: Sinterizado láser de regolito para bloques estructurales y piezas de repuesto

🇦🇷 Contribución Argentina al Código Marte

⚛️
INVAP - Energía Nuclear
Reactor micro-SMR de 40 kWe (10+ años sin recarga). Experiencia: RA-6, RA-8, RA-10 (30 MW en construcción). Exportaciones a 7 países. Ciclo completo de combustible nuclear.
🛰️
CONAE - Comunicaciones Espaciales
Satélites repetidores en órbita marciana (SABIA-Mar, SARE). Estación CLTC Neuquén + LLAMA. Red de Espacio Profundo del hemisferio sur.
🧬
CONICET - Biotecnología
Materiales porosos funcionales (zeolitas), biorreactores de microalgas, técnicas CRISPR para cultivos resistentes al estrés. Robótica avanzada.
🌾
INTA - Agricultura Extrema
65 años de experiencia en agricultura en ambientes extremos (Patagonia, Puna, ambientes salinos). Agricultura de precisión y cultivos en condiciones adversas.
🔬
INTI - Sensores de Precisión
Sensores de estado sólido para detección de gases (CO, NH₃, VOCs). Instrumentación industrial de alta precisión.
❄️
IAA - Experiencia Antártica
Bases Belgrano II y Carlini: operación en aislamiento extremo (-40°C, 8-14 meses). Protocolos de sistemas cerrados y telemedicina aplicables directamente al hábitat marciano.
